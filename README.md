# 侠之道

第一章：**重归来，战幽灵**。基于 Three.js 的高负载浏览器 3D 游戏，场景、角色、飞剑、城门和幽灵均由代码生成。

## 画质要求

本作采用桌面优先的重型画质：原生设备像素比渲染、4K 实时阴影、Bloom 后期、程序化高分辨率表面纹理、密集场景几何与实时粒子。建议使用支持硬件加速的桌面浏览器和独立显卡；高分辨率屏幕下 GPU 负载会明显增加。此版本不提供低画质或移动端降级模式。

## 运行

在项目目录启动任意静态文件服务器，例如：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。Three.js 从 jsDelivr CDN 加载，运行时需要网络连接。

## 操作

- 电脑：`WASD` 或方向键移动，`空格`挥剑，`E`释放剑气；`Enter`继续对话。
- 手机：左侧虚拟摇杆移动，右侧按钮挥剑和释放剑气；点击对话继续。
